# Works and Publications

This repository is the transmission layer of the Rando Young Intellectual Estate: papers, manuals, essays, experiment guides, illustrated briefs, and synthesis documents intended to make the technical work understandable and inheritable.

Publication is not decoration. It is part of implementation. A system that works only while its creator remembers how to use it has not yet survived.

## Published tools and guides

- **[ChatGPT Archive Toolkit](manuals/chatgpt-archive-browser/README.md)** — local-only tools for turning very large ChatGPT data exports into a searchable chronological conversation archive and auditing `library-files.json` against the physical files actually present in the original export.

## Editorial rules

- Link a publication to the canonical project it describes.
- Distinguish a concept paper from a verified technical guide.
- Keep claims proportional to actual evidence.
- Preserve version numbers and publication dates.
- Prefer one authoritative current edition plus clearly labeled historical editions.
- Keep source/editable material when redistribution rights permit it.
